Sobre o Projeto

Este site foi criado para ajudar pequenos negócios a organizarem pedidos online de forma simples e rápida.

Muitas lanchonetes não possuem sistemas próprios, então esse projeto simula um sistema básico onde o cliente escolhe produtos e vê o valor total.

Vantagens

  • Fácil de usar
  • Cálculo automático
  • Organização de pedidos
